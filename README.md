# Kidus Yosief - Portfolio Website

## Project Overview

This website introduces me, my interests, my projects, and my career goals. It includes three pages: Home, Projects/Work, and About/Contact. I updated my website to improve accessibility and create a consistent design across all three pages.

## 1. Accessibility Improvements

- Added navigation labels to help visitors understand the website menu.

## 2. Visual Design

I used two Gestalt principles to improve my website design.

### Proximity

I used proximity by grouping related information together. For example, I placed each project inside its own card so visitors can easily understand which descriptions belong together.

### Similarity

I used similarity by keeping the same colors, fonts, navigation style, and card designs across all three pages. This makes my website look consistent and organized.

## 3. Color Palette

I used the same color palette across all three pages.

- Background: #F4F7FA
- Main text: #243447
- Navigation: #17324D
- Accent color: #2563EB
- White: #FFFFFF

I used the WebAIM Contrast Checker to review text and background color combinations for WCAG AA contrast.

## 4. Accessible Contact Form

I added a contact form to my About/Contact page.

The form includes:
- Full name
- Email address
- Message
- Submit button

I used label elements to identify each field and fieldset and legend to group related information. I also added error messages to help visitors correct missing or invalid information.

The form currently checks the information entered but does not send messages.

This project helped me understand the importance of accessibility and visual design. I learned how to organize website content, create an accessible contact form, use Gestalt principles, and make my website easier for different people to use.
